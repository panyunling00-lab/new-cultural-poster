# 字体配对指南

在步骤 5 与 7 组装提示之前阅读。依据文化主题、活动目的、已批准概念、文案长度与可读性进行选择。主题列表是起点，而非固定指派。下列家族名称用于标识灵感来源，而非图像模型必须加载的字体。

## 八个配对是灵感，不是准入条件

这八个配对是灵感与导航，不是硬性准入清单。字形处理——变形、扭曲、拉伸、网点化、立体化、混搭——在当前排版档位允许的范围内可用：自由档允许自由处理，约束档要求表现性字形保持在其限度内。默认档为 `design-free-v1`，通过 `brief.typography_profile` 切换。所有字号、角色比例、字重、行距、字距、家族数量、留白比例与避让间距均来自当前档位——`references/typography-constraints.md`、`references/typography-system.md` 与 `assets/typography-defaults.json`。字形手法参见 `references/typography-moves.md`。原文准确与正常尺寸可读是底线。

## 配对规则

- 中西配对固定：中文定气质，拉丁字体跟随。书卷印刷配衬线拉丁，粗黑冲击配超粗拉丁；不中西各用各的。仅包含文案中实际提供的文字系统。
- 配对可选；配对数量与字形处理须服务主题和可读性，并按当前排版档位执行。
- Prompt 中用字形特征描述引导生成，绝不直接依赖字体文件名。Integrated 提示仅包含视觉描述：省略家族名称、文件名与字体路径。移除字体库后 Integrated 仍然可用；精确的渲染字形仍需目视审查。

## 1. 中性现代

- 配对名称：中性现代
- 中西字体组合（灵感标签）：Satoshi + MiSans
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：几何无衬线字形，字面比例均匀，笔画偏细至中等；拉丁：几何无衬线，字宽均衡，笔画粗细匹配；克制而宽松的字距。
- 气质关键词：冷静中性
- 适用主题：展览、美术馆、科技文化
- 使用规则：使用匹配的字重与平静的间距；信息文字保持较小但清晰可读。

## 2. 几何圆润

- 配对名称：几何圆润
- 中西字体组合（灵感标签）：ITC Avant Garde Gothic + Alibaba PuHuiTi 2.0
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：友好的几何无衬线，笔画末端柔化，字重中等偏粗；拉丁：圆形几何形态，外观圆润，笔画粗度匹配（中至粗）。
- 气质关键词：年轻友好
- 适用主题：亲子活动、创意市集
- 使用规则：对齐圆润的节奏与感知字重；除非主题支持，避免幼稚的装饰。

## 3. 粗黑冲击

- 配对名称：粗黑冲击
- 中西字体组合（灵感标签）：Helvetica Neue + Plix
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：极重且紧凑的黑色笔画，字面比例压缩；拉丁：特粗压缩大写，视觉重量向下密集；大标题与信息之间对比强烈。
- 气质关键词：力量硬朗
- 适用主题：音乐节、潮流文化、讲座
- 使用规则：将冲击力用于大标题，信息处理更平静；不要缩小功能性文字。

## 4. 优雅衬线

- 配对名称：优雅衬线
- 中西字体组合（灵感标签）：PingFang + MingLiU
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：纤细的宋/明体字形，横画细、竖画较粗；拉丁：精致衬线字形，比例修长，字距宽松。
- 气质关键词：雅致正式
- 适用主题：开幕式、颁奖、高雅艺术
- 使用规则：这些家族标签仅为灵感：PingFang 并非衬线字体。integrated 遵循所描述的衬线外观；overlay 使用 MiSans 加一款字库衬线字体作为替代。

## 5. 对比衬线

- 配对名称：对比衬线
- 中西字体组合（灵感标签）：Classy Vogue + Source Han Serif CN
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：高对比宋体笔画，衬线锐利；拉丁：高对比编辑风格衬线，细发丝线与强竖画；精致的杂志式间距。
- 气质关键词：时尚编辑感
- 适用主题：设计展、时尚文化活动
- 使用规则：在中文与拉丁之间协调笔画对比；确保发丝线在交付尺寸下可读。

## 6. 温暖手写

- 配对名称：温暖手写
- 中西字体组合（灵感标签）：FontQu Smile（字制区喜脉喜欢体）
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：温暖的手写笔画，圆润连贯的笔势，节奏略带不规则；拉丁（若提供）：匹配的柔和手写形态，具有相同的随意节奏。
- 气质关键词：亲切治愈
- 适用主题：手作市集、读书会、咖啡文化
- 使用规则：手写由主题决定，可采用表现性字形；信息保持可读，不要主动添加拉丁文案。

## 7. 书卷印刷

- 配对名称：书卷印刷
- 中西字体组合（灵感标签）：HWMCT（汇文明朝体）
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：印刷感的明/宋体形态，笔画对比适中，书卷节奏均衡；拉丁（若提供）：克制的书籍衬线，字重与间距相当。
- 气质关键词：古朴书卷
- 适用主题：古籍展、书法展、非遗
- 使用规则：将书卷感的中文与衬线拉丁配对；避免自动添加仿古纸张或历史纹样。

## 8. 华丽衬线

- 配对名称：华丽衬线
- 中西字体组合（灵感标签）：Kudry + Source Han Serif CN
- Prompt-ready visual description（可直接用于提示的视觉描述）：中文：表现力强的高对比宋体展示字形；拉丁：华丽衬线展示字形，曲线夸张，字距严格控制；戏剧化强调。
- 气质关键词：华丽戏剧
- 适用主题：晚会、周年庆、品牌夜
- 使用规则：装饰仅限标题；功能性信息保持简洁可读。

## 选择并表达字体风格

本包**不附带字体文件**。上述配对完全通过语言选择并应用：

1. **按描述选择，而非按名称选择。** 将配对与已批准画风定义的配色、材质与文化语域、文案语气及投放渠道相匹配。灵感标签（Satoshi、MiSans、MingLiU …）标识的是一种观感；它们从不是要加载的字体文件，同一观感可由多种真实字体达成。
2. **在提示中以字形特征表达。** 将每组配对的 *Prompt-ready visual description* 原样用作图像提示的字体排印段落——笔画对比、字重、字面比例、字距、衬线/手写特征。绝不要把字体家族名称、文件名或路径写入图像提示。
3. **让文字系统与语言版本匹配。** 中文版本使用配对的中文描述；纯英文版本使用其拉丁描述。不要把中文描述粘贴到英文海报，也不要在中文海报中留下拉丁占位字形。
4. **记录选择。** 记下选用了哪组配对及原因，以便修正轮次可以直接调整描述，而无需重新推导。

Overlay 排版是一条可选路径，仅在**用户为任务明确提供字体文件**时存在。此时，选择渲染效果与配对描述最匹配的已提供文件，将其登记到渲染请求的 `supplied_fonts` 中，用渲染器核实字形覆盖范围，并记录配对灵感标签与实际文件之间的替换关系。不存在系统字体回退，也不得仅为启用 overlay 而安装、下载或悄悄附带字体；没有提供的文件时，使用 integrated 生成，并将渲染字形作为像素进行审查。

## 方向装配 — 画风-版式-配对一致性

### 传统书卷簇

| 画风 ID | 版式 ID | 配对 | 装饰套件（克制默认） |
|---|---|---|---|

### 现代克制簇

| 画风 ID | 版式 ID | 配对 | 装饰套件（克制默认） |
|---|---|---|---|
| `swiss-editorial`, `minimal-graphic`, `bauhaus-modular`, `monochrome-typographic` | `off-center-hero`, `modular-grid`, `split-vertical`, `large-geometry` | 中性现代、对比衬线 | 几何线条、角标、信息图标、分隔线 |

### 冲击表现簇

| 画风 ID | 版式 ID | 配对 | 装饰套件（克制默认） |
|---|---|---|---|
| `neo-brutalist`, `constructivist-impact`, `pop-commercial`, `futurist-gradient` | `diagonal-dynamic`, `radial-composition`, `large-geometry` | 粗黑冲击、几何圆润 | 斜切、小的已提供数字、类印章小标签 |

### 手作温度簇

| 画风 ID | 版式 ID | 配对 | 装饰套件（克制默认） |
|---|---|---|---|
| `organic-craft`, `screenprint`, `risograph-zine` | `layered-depth`, `frame-within-frame`, `folded-space` | 温暖手写、书卷印刷 | 手绘笔触、邮戳、手写便签、纸张肌理 |

以下气质簇是灵感导航，不是准入条件；可以按主题跨簇或不用配对。

装配规则：

1. 根据主题选择风格、版式与可选字形灵感。
2. 活动分类映射（`event-layout-map.md` + 本文件配对映射）优先决定气质簇，三方向尽量覆盖不同首选、禁止同构。
3. 允许有理由的跨簇字形实验；不改变原文与事实。
4. 风格/布局冲突仍按 `selection-guide.md` §7 处理。
