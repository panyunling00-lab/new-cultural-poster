# 文化分类与视觉决策树规则

方向规划开始时读取。由模型先理解实际文档和图片，脚本执行明确规则，不由文件名自动识别文化内容。用户明确选择优先；树只筛选候选，不评价审美，也不替代文化核验、HG2 和终版确认。

## 1. 输入与未知项

脚本：`scripts/decision_tree.py <brief.json>`。输入字段：

- categories：主类在前的 A–H 数组，混合活动合并候选池。
- relation：single（单主体）、many（并列）、process（制作）、comparison（比较）、space（空间）、transformation（转化）、movement（运动）、gathering（聚集）、framed（框景）、symbol（象征）、reading（连贯阅读）、immersive（满版场景）、experimental（非线性）。
- motion：static / dynamic；copy_density：low / high；mood：quiet / expressive。
- specialism：可选 calligraphy / seal-carving / market。
- user_layout：可选，用户明确指定的真实布局 ID；confirmed_layout：可选，已选方向。
- excluded_layouts：经实际文案容量、素材或参考图检查确认不可用的布局数组。未检查不能视为不可用或已通过。

缺失类别、关系、动静、文案密度或气质时返回 needs_analysis，列出缺项；无效枚举返回输入错误。不因未知信息擅自默认。

## 2. 决策顺序

1. 检查用户指定布局，其次检查已确认布局：必须有真实定义，且不违反统一文字规则；可以超出自动分类池，但记录覆盖原因。不能借树改变用户选择。
2. 按活动主类和辅类取 R7 首选、备选的并集，保留主类优先；书法／篆刻 A 增加 diagonal-dynamic，手作市集 C 增加 modular-grid。
3. 按主要表达关系找到匹配布局；只对类别池中的匹配项优先排序，不用路由覆盖类别资格。
4. 高文案密度优先检查分栏、网格及分区容量；动势优先检查方向与聚集关系。这些只是排序提示，不能保证文字放得下。
5. 删除已确认不适用的布局及 big-type-only。空池返回 conflict，不能跨池暗选或删文案。
6. 返回排序候选与三个布局建议。剩余两个以上不同布局时，仍须检查文字区与其他视觉差异；不足三个时返回 needs_adjustment，不能冒充已有三个方向。固定布局可通过不同空间、主体或材质形成三方向，但须独立设计。

## 4. 脚本之后的设计判断

候选只是结构选择。每个方向仍需写明文化核心、主题到视觉的关系、主体尺度、构图依据和文字承载区。不得用「高级」「文化感」替代具体方案。

按规范文件名选择风格与布局，实际读取定义并检查相关参考图。路径不等于已查看，已查看不等于已提交。风格负责颜色、字形性格、材质和光影；布局负责位置、尺度、空间和阅读顺序。一个主风格、一个主构图机制，不堆叠全部效果。

遵循当前排版档位：默认档为 `design-free-v1`，通过 `brief.typography_profile` 切换。档位总入口与 design-free 档规则见 `references/typography-constraints.md`；small-type 档规则见 `references/typography-system.md`；数值来源为 `assets/typography-defaults.json`。不要在此复述其数值上限。安静机构活动不因追求表现力擅自变成高能量现场风格；高能量／实验风格须符合活动或用户明确选择。展览、博物馆与非遗活动至少一个方向强调开放空间与克制配色。类别首选布局不被一般风格偏好排除。

### 纵深优先候选

文化展览、演出及空间类活动优先评估 depth 型：`layered-depth`、`frame-within-frame`、`off-center-hero`、`full-bleed-image-overlay`、`folded-space`、`axonometric-spatial`；从对应类别候选池选择，明确用户选择优先。A/B/C 除信息区位置外，还必须区别空间层级与纵深机制——纸层遮挡、开口框景、折面或平行投影——不以颜色变化代替纵深差异。

### 风格光谱（主题主导的多样性）

Style 按主题选。A/B/C 三张应覆盖一个**风格光谱**，而不是三张都往猛里做：

- 一张走安静／简约／淡彩路线（参考 style：`japanese-ma`、`swiss-editorial`、`minimal-graphic`、`luxury-minimal`、`botanical-premium`、`cultural-editorial`；参考布局：`minimal-white-space`）——低饱和、高明度、大量留白、呼吸感强；配色倾向米白、浅青、雾灰、淡赭与少量墨色，或极克制的现代中性色。字与图小而精，不争抢视觉重心，尺度以正常观看尺寸可读为底线；主题需要时可以有一个极小的人物、器物或建筑剪影作为意境锚点。安静／简约不等于高对比大色块：禁止深蓝、大红、亮金、荧光等强对比色铺满画面，配色必须真正清淡，不能用高饱和特写替代呼吸感。
- 一张走中等设计感路线（`editorial-collage`、`image-led-editorial`、`cultural-editorial`、`organic-craft`、`screenprint` 等）——有排版巧思但不吵闹。
- 一张走冲击／实验路线（`neo-brutalist`、`constructivist-impact`、`pop-commercial`、`futurist-gradient`、`y2k`、`glitch-art`、`kinetic-typography`、`distorted-type`）——大字、高对比、变形、网点、立体。

三张之间媒介／画法、构图、字形处理必须明显不同；禁止仅换配色或位置。不再强制同气质簇。主题本身强烈时可以三张都偏冲击；主题本身安静时可以三张都偏安静；默认情况下三张拉开光谱。素雅和冲击都是合法选项，按主题和光谱分布决定；明确用户风格要求优先。安静路线的配色限制不适用于中等设计感或冲击／实验路线。

### 东方雅致路线

这是一种有明确构成语言的方向，不是所有主题的默认纸风；在主题与文化语境支持时，优先作为光谱中安静那张的候选。以现代构成结合东方意境：大面积留白与一个极简的器物、建筑或人物剪影建立尺度关系，克制色块分割与几何留白形成秩序，主题相关的自然意象或曲线动线连接画面。意境锚点可极小，但不强制加入人物。

采用低饱和的姜黄、赭石、石青、米白与墨色的克制搭配，保持高明度和充足呼吸感；避免大红大绿与满版填充。可用轻微宣纸或绢本质感，但不堆砌纹理，不把纸纤维加自然意象当作完成设计。标题可用宋体、衬线或楷体特征，配合竖排、错落、与图形穿插等现代处理；必要时以单个较大标题回应留白，仍保持整体克制。高级感来自比例、色块关系、视觉动线与字图关系，而不是装饰数量或材质滤镜。

### 观察检查清单

对每个候选，说明其相关性、观察到的机制、必备特征、可替换内容与冲突风险。

观察：
- 主色与点缀色、明度与饱和度。
- 字体字重、比例、间距与形变。
- 摄影、插画、图形或 3D 处理。
- 材质、边缘、光照、阴影与反射。
- 一个主导的印刷、数字、形变或空间机制。

不要用 premium 或 sophisticated 等含糊词语替代观察。定义中列出的效果是可选用语，而非需要逐条累积的清单。所观察到的参考机制决定所选分支，且 A/B/C 的材质与媒介必须明显不同。在选择前解决明显的定义与图片冲突。

## 5. 可用性与冲突检查

确认完整必需文案、素材角色与许可、画幅和渠道。不可编造事实、翻译、标志、文化符号或删必需文案。参考中的文字与主体不自动属于本任务。

只查看相关原图；风格入口为 `assets/style-references/index.md`，构图入口为 `assets/composition-references/<group>/<layout_id>/`。不全量加载素材库。选择真实可访问参考，不能静默换库。可直接传图，或在实际看图后提取特征；记录工具实际收到的图片，不把路径当成提交。

检查完整文案能否在当前排版档位下容纳、文字区域是否足够，以及三个方向是否至少在两个视觉维度有区别。遇冲突调整布局、分组或画布，不无限缩字。稀疏参考不靠微字容纳密集信息；居中不等于放射，倾斜不等于折叠，平面贴图不等于纵深。像素、丝网、流体等风格遵守各自机制；日式灵感不授权增加日文。

### 生成门槛

确定传达目标、主题、受众、完整的必需文案、主体素材、变换许可、语言、渠道、尺寸、比例与品牌识别约束。不要编造活动事实、数据、文化归属、价格或宣传语。有主题依据的视觉诠释是允许的，并标记为 Inferred。参考海报中的文本与 logo 不属于当前任务的内容。

依据实际文案评估密度。长标题、双语文本、日程表与多个 logo 都会提高密度。绝不要为迁就参考而删除必需内容，或将其缩到无法阅读。

生成前，确认：
- 所选择的定义存在且已阅读。
- 素材映射无歧义。
- 图片存在、可访问且可解码。
- 图片已实际查看且与各自定义相符。
- 主体、比例与必需文案都能放得下。
- 已选择受支持的参考使用模式。

目录列表或路径不构成对图片的查看。若任一强制门槛未通过，停止生成并报告确切的阻塞点。特征提取须在实际查看图片之后进行；不要用缺乏依据的纯文本即兴发挥或另一个库来替代。

### 角色与冲突规则

画风参考控制色彩、字体气质、图像处理、材质、光照与效果。版式参考控制主体位置、尺度关系、区域、负空间、纵深与阅读顺序。不要照搬两个彼此独立的构图。

替换存在冲突的自动候选。对于明确指定的组合，应说明冲突，并在渲染前取得必要的取舍决定。

- 稀疏的参考无法通过微缩字号来容纳密集文案。
- 单色字体类画风不得加入占主导的彩色摄影。
- 实体印刷错误不能用随意的数字故障效果替代。
- 像素艺术需要一致的网格；丝网印需要可信的墨层。
- 流体视觉必须选定 2D 或 3D 分支。
- Y2K 处理必须遵循某一具体参考分支，而非堆砌所有该时代母题。
- 日式灵感画风并不授权添加日文文本。
- 轴向秩序与主导性失序并非默认搭配。

### 参考使用模式

选择一张主要画风图片与一张主要版式图片。仅在必要时添加辅助图片。在同一类别内，优先考虑与定义契合、比例兼容、文案容量与特征清晰。不要把整个类别提交给模型去做平均。遵守渲染器限制。

阅读定义、查看原始图并记录要借鉴的特征。选择一种受支持的模式：

1. 特征提取：在生成提示词中描述观察到的画风特征与版式关系。当不支持直接图像输入或无需直接输入时可用。记录的参考状态为已查看，而非已提交。
2. 直接参考：通过受支持的工具输入提交图片，并指明其顺序与角色。画风控制处理方式，版式控制空间。仅有路径或描述不构成提交。不要沿用参考中的文本、logo、主体或无关的文化母题。

执行机器无法访问的 Windows 路径不是有效的渲染器输入。若两张图片都无法提交，则对不受支持的角色（或两个角色）改用特征提取。不要假定支持参考板（reference board）。不要声称未经核实的变通方法有效。

主体素材与参考图用途不同。允许创建新主体并不免除对参考的要求。

## 6. 记录与结果

保留输入判断、来源依据、脚本理由、风格与布局 ID、参考角色、完整文案与画幅。普通任务记录即可，不要求私有推理。生成后查看实际图片，检查事实、文化内容、主构图、材质、文字与额外内容；脚本成功不表示质量通过。已选方案局部优化不得静默重新设计；沿用原有质量与人工确认流程。

### 生成契约

在每次生成／编辑提示词以及所有 overlay 备注中包含完整的共享排版约束块。生成前记录标题处理、阅读顺序、预期展示尺寸与计划中的穿插。字体是否可以成为主要视觉设计对象，取决于当前排版档位。

生成前，确定概念、一个锚点、两个 ID、参考角色、必备特征、信息区域、阅读路径、比例与完整文案。

只组合已确认的内容、所选择的定义、观察到的特征与必要的适配。不要粘贴整个库。允许在色彩微妙差异、局部形态、材质表现与场景细节上有界地自由发挥，同时保持不变的是构图、已验证的文化含义、完整文案与已批准的方向。

允许在既定视觉语言之内进行已确认的主体与文案替换、格式适配与可读性调整。禁止静默更改画风或版式、引入第二个主导机制、添加不受支持的装饰、无关的品牌元素、编造事实或遗漏必需内容。声称改进或更精致，并不授权更改已确认的设计。当要求无法调和时，返回选择环节。

### 输出审查

打开输出，将其与已查看的参考、记录的特征（以及适用时已提交的图片）进行比对，检查：
1. 事实与必需措辞。
2. 主体摆放、区域、尺度关系、空间与阅读顺序。
3. 色彩、排版、材质、光照与主要效果。
4. 在预期观看尺寸下的可读性。
5. 多余的画风、装饰、品牌元素或编造内容。

为每个项目记录通过、不通过或未核实，并附具体差异。提示词成功或渲染器调用成功，并不代表结果令人满意。

不得将存在事实错误、必需文案不可读、主要版式偏离或画风机制缺失的结果作为完成品交付。在进行针对性修正期间，继续使用原始参考。要求满足后即停止无关的修改，并报告持续存在的渲染器限制，而不要承诺完全一致。

## 人物规则与连续画面

本规则在两档排版配置下都生效，适用于全部 A/B/C 与后续细化。

从简报解析人物策略（`scripts/build_prompt.py::people_policy`）：主题类别含演出（B）、节庆/嘉年华（E）或集市，或用户参考素材仅含人物（`reference_people: "only-people"`）时，允许人物；参考素材同时含人物与其他内容（`reference_people: "people-plus-content"`）时，尽量不以人物作主体，仅在没有其他内容能承载主题时才使用人物；其余全部情况下不使用人物作为视觉主体，也不生成真人、插画人物、剪影、手部特写或微型人物场景。默认情形下，选材优先非人物器物、材料、工艺结构、自然形态与抽象关系，也不优先选用人物造型的器物和作品。原始素材必须展示且本身有人物形象时，不擅自篡改或删除，先说明冲突并取得明确决定。默认情形下没有合适无人素材时用有文化依据的材料或结构表达，不编造替代展品。

禁止明显分格的多图拼版：九宫格、卡片墙、上方一图下方两格细节放大图、带白色分隔线的摄影拼贴等。采用连续完整的视觉空间，以大形、尺度、留白和前后关系组织。隐藏的对齐网格仍可使用，但不能画成可见格子。默认排除 `modular-grid`、`split-horizontal`、`split-vertical`；框景仅允许单一连续窗口，不做多格。

三个不同风格和构图仍须从剩余合适候选选择；候选不足时说明并调整类别适配，不暗中恢复禁用布局。只有用户后续明确改变要求才能解除相应限制。
