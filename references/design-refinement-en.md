# 文化活动主视觉的设计精修

## 1. 使用时机与目的

本参考只在 HG2 之后、用户已选定实际图片时阅读，并在完成海报之前执行。选定图像是最终基准，而非重新生成或制作变体的信号。只修正错别字、缺失字形/文案、伪文字、意外结构缺陷以及必要的局部可读性问题。不得改变主体角度、配色或信息区安排。重大构图/画风改动回到第 5 步重新三选一并在 HG2 确认。保留人工门。

以选定的图像作为编辑或合成的基底。保留其主题表达、主体、构图、配色与主要材质处理。找出对完成质量影响最大的 1–3 个问题，再做针对性调整。精修只修正局部文字或意外缺陷；不得增删有意的装饰或重排已批准的设计。若设计已成熟，只做必要改进。

加载当前排版档位：`references/typography-constraints.md`、`references/typography-system.md` 与数值唯一来源 `assets/typography-defaults.json`。档位由 `brief.typography_profile` 选择，默认 `design-free-v1`。字号、角色比例、字重、行距、字距、家族数量、留白比例与避让间距一律按该档位执行；下文的可选网格示例不能覆盖它。文化准确性、事实与必需素材覆盖度仍由主 Skill 与质量评分标准管辖。未指定的名称、日期、地点及其他事实一律留空；不要为填充版式而虚构文案。

## 2. 五项设计原则

### 2.1 限制字体家族数量

字体家族数量按当前排版档位执行，由档位给出默认家族数量与上限；保留已选定的设计字形。同一家族内的不同字重不计为额外家族。配对的中文与拉丁字体按实际家族记录。变化必须服务于不同的文字角色，而非装饰。

依据主题、形式、文案长度与可读性选择字体排印。integrated 使用 `references/font-pairing-guide.md` 中的视觉配对；overlay 则将其映射到第 6 节所记录的用户提供字体。画风术语描述的是外观，而非加载其他字体的授权。

### 2.2 建立首要视觉焦点

视觉焦点可以是设计字形、物件、空间、主题图形或插画；除简报解析出的人物策略允许外（演出、节庆/嘉年华、集市类主题，或参考素材仅含人物），不使用人物作为视觉主体，也不生成人物。保留已选定的图文关系，包括满版叠压与可辨识的局部遮挡。将标题置于版式定义的文字区内；与受保护主体边界的避让间距按当前排版档位执行。

### 2.3 组织负空间

负空间支撑强调、分组与阅读顺序。优先选择有意图的连续空间，而非意外产生的碎片化空隙。这并不意味着留白越少越好。负空间比例与为文字预留的内边距按当前排版档位执行。

### 2.4 控制主要色彩角色

从 1–3 个主要色彩角色开始：主色、辅色与点缀色。同一色相家族内的明度变化可共用同一角色。黑、白、灰按其实际视觉功能计算。不要机械地统计照片或素材中的每一种自然色。

多色、节庆或实验性设计在主导关系依然清晰时可以使用更多颜色。不要把每个文化主题都变成红金、低饱和色调或米色。

### 2.5 管理字体尺度对比

尺度对比是最大文字与最小文字之间的关系。较低对比可支撑克制与持续阅读；较高对比可支撑活力与冲击力。依据活动目的与已批准方向选择。

不要通过无限缩小日期、地点或正文来提升对比。只修复局部可读性问题；字号上限与角色比例按当前排版档位执行。

## 3. 字号与行距关系

### 3.1 区分可见字形高度、字号与行距

所提供的参考图示使用可见字形高度与文本块边界。它们并不直接规定软件字号。字体在字形与 em 的比例、大小写、上伸部、下伸部以及中文/拉丁的感知字重上各不相同。

- a：主标题的可见字形高度。
- b 与 c：次级与三级文字的可见字形高度。
- x 与 y：相邻行可见字形边缘之间的清晰间隙。
- L：基线到基线的间距，通常称为行距或行高。对于同类行，约为 L=b+x 或 c+y；实际字体度量与目视检查优先。

### 3.2 等高文本块 — 参考图 1 与 2

图示展示一行大字、两行中等字与三行小字占据相同的可见块高 a：

```text
主标题：a
次级：2b + x = a
三级：3c + 2y = a
一般形式：n × 字形高度 h + (n−1) × 清晰间隙 g = 块高 H
```

因此 b=(a−x)/2，c=(a−2y)/3。不要假定字号比例强制为 1:0.5:0.333；清晰间隙同样占据空间。

若 x=k₂b 且 y=k₃c：

```text
b/a = 1/(2+k₂)
c/a = 1/(3+2k₃)
```

示例计算（为选定的数值，而非从图像测量所得）：当 a=120、k₂=0.4、k₃=0.6 时，b=50、x=20、c≈28.6、y≈17.1。每个块高 120 单位；近似基线间距为 70 与 45.7 单位。

等高模块可支撑并置、分栏与编辑式版式。它们是可选项。不要为强行凑成两行或三行而改动必需文案，也不要把三级文字缩小到不可读。

### 3.3 层级内一致与层级间清晰 — 图 2–4

对于并排的块，共享顶边、底边或主要对齐轴。对于纵向排列的块，保持一致的距离节奏。图 3 将大标题与三级块并置，次级文字位于另一行。图 4 采用居中的纵向层级。相似的字体尺度可以支撑不同的组织结构。

图示中的彩色结构标记用于解释关系；它们不是海报必需的装饰。它们并不确立精确的通用段落间距。依据实际块与阅读分组调整间距。

### 3.4 其他版式的建议初始值

这些是模块建议，并非所提供图像的测量值或通用行业标准；约束性的角色字号与行距来自当前排版档位（`assets/typography-defaults.json`）。设 S 为主标题的名义字号：

| 角色 | 初始字号 | 基线间距 / 名义字号 |
|---|---|---|
| 主标题 | S | 多行中文从 1.05–1.25 起 |
| 副标题或主题说明 | 按当前排版档位执行 | 1.20–1.45 |
| 关键活动信息，如日期与场地 | 按当前排版档位执行 | 1.25–1.55 |
| 较长的中文正文文案 | 按当前排版档位执行；核实目标尺寸下的可读性 | 1.40–1.70 |

全大写拉丁标题在适用时可采用更紧的间距；检查笔画与纵向范围。相同名义字号的中文/拉丁并不保证相同的感知大小。对长标题、竖排、书法、粗字重、双语版式与密集内容，需重新考虑这些数值。基线间距与清晰字形间隙 x/y 是不同的量。

信息组内的间距应小于组与组之间的间距。在有意义的情况下，组间清晰间隙约为组内间隙的 1.5–2 倍可作为起点。不要将这一关系强加于没有可比内部间距的单行组，也不要据此覆盖已批准的实验性构图。对齐、分隔线或背景场域同样可以建立分组。

字号上限按当前排版档位执行，可读性下限按目标投放渠道设定。测量完整标题块，而非单个字形。依据交付尺寸、观看距离、字形比例与文案长度判定可读性。在目标显示尺寸下检查，而不只是放大检查。图像像素不得直接解读为印刷点。

## 4. 网格、页边距与比例

参考图 5 展示了一个黄金比例网格。作为可选定位辅助，可在可用版式尺寸的约 38.2% 与 61.8% 处放置参考线，以探索主体、文本块与分区关系。这些数值源自约 1:1.618；并非每个画布或元素都需要黄金分割。

在选择模块化网格、中心轴、分栏或黄金比例参考线之前，先遵循已批准的构图与信息逻辑。除非明确属于设计的一部分，构建网格在最终作品中应保持不可见。不要要求同时使用多种网格。在页边距、栏间距与组间距中建立重复节奏，并针对曲线、书法与不规则主体进行视觉修正。

## 5. 将大标题与图像一同设计

保留已批准的大标题与图像之间的主要关系：大字叠压、前景遮挡、轮廓对齐、穿插或安静的并置。不要使用带可见分格的多图拼版，框景只允许单一的连续窗口。

大标题可以在保持名称辨识度的同时表达工艺与材质质感。每一项必需内容都必须保持可辨识；当实际阅读依然清晰时允许局部遮挡，且活动文案位于当前排版档位定义的安全区内。通过尺度、轮廓、方向或材质连接文字与图像，而不是随意附加一个漂浮标签。

用目的与形式引导强调重点：展览可强调主题与作品间的关系；讲座可强调议题与信息结构；节庆可强调参与与氛围；工作坊可强调动手与体验。这些是判断线索，而非固定的画风指派。

通过物件、材质、动作、空间或观念表达文化内容。不要为泛泛的“文化感”添加无依据的符号。区分艺术诠释与事实重建。在质量评分标准下核实具体的纹样、服饰、宗教元素与历史物件。

## 6. 字体配对与制作模式

### 6.1 integrated

阅读 `references/font-pairing-guide.md`。在图像提示中使用其协调的中文/拉丁视觉描述作为灵感配对；配对数量按当前排版档位执行。不要把字体名称、文件名或路径写入 integrated 提示。无需真实字体文件；移除整个字体库不会影响配对选择或提示构建。审查实际生成的文字与字形；描述引导外观，但不保证文字完全准确。通过编辑修正生成的文字，或在需要可靠排版时选择 overlay，而不是为每张 integrated 海报都要求 overlay。

### 6.2 overlay

本包不附带字体文件。Integrated 生成从不依赖字体。Overlay 排版需要用户按 references/font-pairing-guide.md 提供的字体文件；将提供的文件记录在任务记录中，对缺失字形使用最接近的已提供匹配，并报告无法解析的文案，而不是静默使用系统字体。

## 7. 用户提供的场地及其他图像

区分实际主体素材、对保真度敏感的照片、画风参考与构图参考。来自参考示例的文字与标识不是本次活动的文案。

用于场地宣传时，在已批准方向内进行裁切、调色、排版或编辑，同时保留可辨识的建筑结构。不要虚构建筑的改动、不存在的展品或标识。强烈的插画化或抽象处理必须符合用户已确认的意图。对已批准核心方向的改动需回到 HG2。

## 8. 精修计划与后续步骤

编辑前，准备一份简明的计划：

```text
已选图像与版本：
保留：主体、概念、构图、配色、主要材质处理
优先改进项：最多 1–3 项；指明位置、问题与措施
字体排印档位：取自 brief.typography_profile；默认 design-free-v1
字体排印角色：家族/特征、字重、名义字号与角色比例
标题处理与阅读顺序：保留已选字形；字号上限按当前档位执行
可读性：实际观看尺寸、字符保真度与对比
图层关系：保留已选的叠压与前景蒙版
行距与分组：清晰字形间隙或基线间距；指明单位与含义
图文关系：一种主要关系
制作：已选图像编辑 / 精确排版 / 图层合成
验证：目标显示尺寸、整体视图、文字细节、实际文件属性
```

将该计划传递给 base-prompt 模块以组装编辑指令。不要把整篇文档、评分语言或示例文案粘贴到渲染器提示中。比较前后版本；核实已批准方向是否得到保留，并保留前一版本。

继续主 Skill 的质量评审与 HG3。本模块不批准海报、不绕过脚本，也不自动导出。数值关系支撑设计决策；它们不能替代实际图像检查。
