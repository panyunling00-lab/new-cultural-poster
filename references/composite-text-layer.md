# 模型绘制文字层与本地混合（composite 路径）

第三条文字路径，与 integrated、字体版 overlay 并列。适用于：文字需要反复修订而不想重画底图，或多个语言版本共享同一张已批准底图。首次进行 composite 制作前阅读本文件。全程不涉及任何字体文件。字体与几何规则见当前档位 `references/typography-constraints.md`；质检范围引用 `references/quality-rubric-en.md`。

## 分工

- 图像模型绘制文字层：字体设计、来自所选配对视觉描述的字形特征、确切文案。
- 本地代码只做裁剪、缩放、定位、混合与不透明度调整。绝不在本地重绘、重新排版、矢量化或“修字”。
- 底图只生成一次、无文字，遵循与 overlay 底图相同的规则（预留安静区、无字母、无伪文字）。
- 必需的 logo 与二维码使用原始资产独立合成，图像模型绝不重绘。
- 所有字体、字阶、边距与测量规则只来自当前档位。

## 何时选 composite 而不是 integrated

- 文字大概率要改：只重新生成文字层，已批准的底图保留。
- 多版本交付：底图生成一次，各语言版本各生成一张自己的文字层；每个版本仍独立通过步骤 7–11 与 HG3。
- 底图嵌入了用户摄影素材或高成本图生图结果，不允许内容漂移。
对于没有修订压力的简单单版本，integrated 仍是更省的默认（四次生成而非五次）。

## 文字层输入

提供确切文案、字形视觉描述、文字区域、画幅、阅读顺序及与底图的关系。不自动增加译文、宣传语、署名、日期或机构信息。只有任务要求的语言才出现。

优先透明背景；使用随附混合脚本时，文字层须为纯黑底浅字或纯白底深字，不含场景、渐变或背景纹理。文字本身可有合适材质，但不可牺牲准确性与辨识。

## 文字层生成规则

一次生成调用，产出一张文字层图：

- 画布比例与已确认海报画布一致。整幅文字层的合成结果最可预期；已明确放置框时也允许局部文字层。
- 背景：纯 `#000000` 配浅色/白色字（screen 混合），或纯 `#FFFFFF` 配深色字（multiply 混合）。不得有纹理、渐变、场景、边框、暗角或投影——它们在混合下不再保持中性。
- 内容：只有文案清单中的确切字符串，逐字照抄，必需项一个不缺。不得有装饰性伪文字、编造署名、重复或填充字母。
- 字体排印遵循所选配对的视觉描述；绝不出现字体名、文件名或路径。
- 当前档位约束文字层：在合成结果上按该档位的目标与上限测量完整标题块与各角色字号。small-type-refined-v1 档下按 `assets/typography-small-type.json` 的目标与上限执行（标题块、副标题、正文、边距、负空间）；design-free-v1 档下没有数值上限——只有确切文案与预期尺寸可读。

## 本地合成

```text
python scripts/composite_text_layer.py --base <task>/base.png --layer <task>/type-layer.png \
  --out <task>/version-02/composite.png --config-out <task>/version-02/composite-config.json \
  --box 0.06,0.05,0.88,0.30
```

- `--mode auto` 读取文字层四角的亮度：接近纯黑选 screen，接近纯白选 multiply，其余一律拒绝。中灰背景说明文字层没有按本规范生成——重新生成文字层，不要在本地抠图。
- screen 保持黑色中性、multiply 保持白色中性，因此未印字区域绝不改变底图。模式与背景不匹配会让整张海报变暗或泛白；脚本的拒绝机制是硬性护栏，不是建议。
- 保护原始底图：错误文字只重新生成受影响的文字层，绝不重做整张底图；需要遮挡关系时使用独立前景或蒙版，不盲目叠字。
- 脚本拒绝覆盖底图或文字层，并记录配置 JSON（路径、SHA-256、模式、放置框、不透明度、输出哈希）。相同输入重跑结果逐字节一致；只换文字层即可修订文字而不动底图。

## 标准产物

每个版本把四件保存到任务输出目录：无字 `base`、`文字层`、`合成图`、`composite-config.json`。多语言版本可共享底图，文字层独立布局。它们是工作稿——脚本配置是内部制作记录，不要求用户手工填写；导出批准仍走正常门控。

## 审查

- 混合前，在全分辨率下对照文案清单逐字核验文字层。错字或缺字意味着重新生成文字层——绝不重画底图，也绝不在本地补字。
- 合成后，从合成像素上取排印证据（标题块边界、角色字号、文字块间距）连同 `scripts/check_poster.py` 提交。合成成功不能证明尺寸、间距或可读性。
- 模型画的字仍可能写错：文字层只是一次廉价的生成，底图才是贵的资产。这条路径的全部意义就在这个不对称上。

质检范围引用 `references/quality-rubric-en.md`：首次完整检查，后续复查实际变化及影响。合成成功不证明文字正确、位置合规或审美通过；终版确认后原样交付，不另设审批。
