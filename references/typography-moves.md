# 字体玩法菜单

这些是可勾选的灵感，不是完成检查清单，也不是每张必须用的效果。

- [ ] 解构拼字：同标题的不同字可分别用横条纹、网点、卷曲线、粗黑几何或手绘细线构成，让大小与基线有主题性的错落。
- [ ] 毛笔飞白：用自由笔势、墨迹干湿和飞白创造字形，让笔画与图形呼应且名称仍可认。
- [ ] 立体翻边：粗笔画斜切、卷边或翻折，以光照和阴影表现字形厚度。
- [ ] 线描写生：用重叠速写线构成文字骨架，保留关键笔画与字间辨认。
- [ ] 网点颗粒：让字形由网点、磨砂或喷砂渐变形成，密度变化响应主题与媒介。
- [ ] 镜面构字：将笔画转成立体框、盒体或镜面结构，错位叠加但保持正确汉字。
- [ ] 竖排错落：用竖向阅读、大小反差与不齐的起止点建立节奏，功能信息保持可读。
- [ ] 沿路径：字沿主题相关的曲线、轮廓或动线排列（例如器物边缘、动作轨迹、装饰曲线），方向变化不打乱字符顺序。
- [ ] 叠压遮挡：字压图、图压字、色块穿字或跨层，用轮廓与对比保证局部遮挡后仍能读。
- [ ] 截断散落：裁切装饰性延伸、错开字形局部或散置字块，唯一必需文字不可丢失或难以辨认。
- [ ] 印章批注：用主题相关的章形或手写批注组织信息，只使用已有文案，不伪造印文、落款或背书。
- [ ] 大字压满版：让设计过的主标题直接进入满版照片、绘画或渲染图，以尺度冲突形成核心。

按主题选 0–2 个用，不要堆。可以完全不用配对；安静或冲击都必须出于主题与阅读需求。
安静/简约主题可以只用其中 0–1 个手法，甚至完全不用，保持干净呼吸感；不要为了“有趣”而硬加效果。

- [ ] 风格化/解构路线：允许主体裁切出画、局部放大、出框、错位、破碎或只显示局部；前提是不破坏 brief 要求保留的资产及文化识别。标题之外的辅助信息可弱化、缩小；用户 brief 允许删减的可选信息可精简或省略，保留已确认必需的功能信息并确保正常尺寸可读。先确定精简后的 copy_items，再生成；不能把已有必需信息擅自改为可选。以视觉冲击力与形式感为主，不为填满 event_info 而将画面收回整齐；这条路线须适合主题，不是通用默认。

档位适配：本菜单档位中立，可选可不选；在 small-type-refined-v1 档下，凡与档位上限冲突的手法——尤其是「大字压满版」、主体出画、局部放大——按档位上限执行或干脆不用。当前档位的数值与上限见 references/typography-constraints.md。
